# Embracing hero study

Isolated local prototype; not connected to the production homepage or site build.

Serve this directory using a static HTTP server and open index.html. No installation or build is required.

The mascot is an AI-generated transparent asset based on the approved embracing concept. The cutout prompt asked for only Fleek, preserving his embracing pose, crest, cyan eyes and circuit-trace feathers while removing cards, code and background. Generated with the built-in image tool. Commit text is sample content from the supplied wireframe; initials are placeholder avatars, not fetched profile photos.

The canvas background tests moving code within a soft, changing plume silhouette with cyan-to-violet-to-pink color. It is an initial feasibility study, not a reproduction of all the wispy lighting in the approved concept. It uses no Unicorn dependency. Animation pauses offscreen and follows reduced-motion preference; a visible control can override it.

Next visual decisions: mascot scale and overlap, code density, plume shape, and glow intensity. After those are settled, integrate into source/index.jinja and the site's styles.
